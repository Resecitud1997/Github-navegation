# GitHub Advanced Search - Instalador Windows

Este proyecto contiene el archivo HTML de GitHub Advanced Search para navegar desde tu propio navegador

## Archivos del Proyecto

- **index.html** - Aplicación web de búsqueda avanzada en GitHub (sin modificaciones)
- **setup.iss** - Script de Inno Setup para crear el instalador de Windows

Download:

[Descargar archivo](https://raw.githubusercontent.com/Resecitud1997/Github-navegation/blob/44f66e41b06d398a16dfd38529294a67b7b4d4b2/GitHubAdvancedSearch-Setup.exe)

## Uso de la Aplicación

- Obtener tu propio token classic, en tu perfil de github

## Solución de Problemas
100% funcional

### La aplicación no se abre
Verifica que el archivo .html este dentro de la extensión index.html

## Notas

- El archivo HTML no ha sido modificado
- La aplicación requiere conexión a internet para funcionar (usa la API de GitHub)
- Los datos del token se guardan localmente en el navegador del usuario
